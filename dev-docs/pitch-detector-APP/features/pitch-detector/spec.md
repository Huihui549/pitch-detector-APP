# spec.md — 音高检测 Qt 应用（pitch-detector-APP）

- 状态：**已冻结**（2026-09-28 用户拍板：手机优先 / 固定窗 4096 / 单页 + 底部导航 / 调试页隐藏入口）
- 形态：Qt 6.8.3 单代码库，QML 界面 + C++ 算法/流程；**首版目标 Android ARM64-v8a（手机优先）**，桌面同代码库一并构建（开发期验证 + 客户端），嵌入式预留位
- 上游：`[PC] D:\dev_project\pitch-detector`（网页版，只读）

## 一、需求

### 输入 → 处理 → 输出

| 环节 | 内容 |
|---|---|
| 输入 | ① 麦克风实时流（`[PC]` / `[手机]` / 未来 `[开发板]`）② 音频文件（WAV 必做；其它格式视 Qt 解码能力决定，见"待定"） |
| 处理 | 与上游**逐参数一致**的 YIN 基频估计（级联窗长 + τ 精修 + 频域精修 + 谐波一致性复核）→ 八度轨迹校正 → 十二平均律音名与音分偏差 |
| 输出 | 界面：大字音名 + 八度 + 音分条（±50 音分）+ 音高曲线；文件：CSV 时间序列；音频：WAV 导出（调试用） |

### 功能范围（首版）

| # | 功能 | 说明 | 来源 |
|---|---|---|---|
| F1 | 实时音高显示 | 大字音名、音分条、当前 Hz、近 5 秒曲线 | 上游「实时反馈」页 |
| F2 | 文件分析 | 导入音频 → 逐帧音高 → 曲线 + 音符段表 + 统计 + CSV 导出 | 上游「录音分析」页 |
| F3 | 音域测量 | 本次会话最高/最低音、跨度（半音数与八度）、累计有效时长 | 上游「音域测量」页 |
| F4 | 调试信息 | 置信度、RMS、实际采集格式、τ 谷值曲线、削顶提示 | 上游 `debug.html`（首版是否纳入见"待定"） |
| F5 | 参数设置 | A4 基准（默认 440）、置信度门槛显示 | 上游界面可改 A4 |

### 明确不做（沿用上游）

和弦与多音高检测；评分与排名；云端、账号、历史同步；伴奏与节拍器；任何第三方 DSP/音频库（YIN 自实现）；iOS（开发机为 Windows，无构建链）。

### 已冻结决策（2026-09-28）

| 事项 | 决定 |
|---|---|
| 首版平台 | **手机 APP 优先**（Android ARM64-v8a）；桌面同代码库构建 |
| 界面形态 | 单页 + 底部导航栏（实时 / 文件 / 音域 / 更多） |
| 实时链路窗长 | 固定窗 4096（沿用上游，先保证逐帧可对拍；切换条件见 ADR-0004） |
| 调试页 | 进首版，**隐藏入口**（连点标题区 7 次进入） |
| 文件格式 | 首版仅未压缩 PCM WAV（与上游离线分析口径一致） |

### 「更多」页内容（首版）

A4 基准设置（默认 440）、App 版本与构建信息、调试入口（隐藏，连点标题区 7 次）、关于/许可（Qt 采用 LGPLv3 时的声明义务）。

## 二、边界与异常

| 场景 | 要求的行为 |
|---|---|
| 无可用录音设备 | 显式提示"未找到音频输入设备"与恢复建议，不静默失败 |
| 麦克风权限被拒 | 显示原因与恢复指引，不重复弹窗骚扰（Android 需运行期权限） |
| 实际采集格式与请求不符 | 按**实际格式**换算 τ，并在调试信息中显示协商结果（pitfalls A3） |
| 信号过弱（RMS 低于门槛） | 音名显示「—」，不显示上一次的残留值 |
| 置信度不足 | 同上，且曲线不写入该帧 |
| 频率超出当前模式音域 | 显示「—」并提示超范围，不计入音域极值 |
| 和弦/多音同时发声 | 显示「信号不稳」，不做多音高估计 |
| 导入文件格式不支持 | 提示不支持并列出可支持格式，不崩溃 |
| 空文件或纯静音文件 | 给出「未检测到有效音高」，不导出空表 |
| 文件分析进行中 | 界面可取消；进度可见；取消后不残留半成品结果 |
| 采样率非 44.1 kHz（如 48 kHz） | τ 按实际采样率换算，不假定 44.1 kHz |

## 三、验收标准

### A 组｜算法正确性（与上游等价，AI 自动）

| # | 判据 | 通过标准 |
|---|---|---|
| A1 | 上游 88 键素材 | 命中 **≥ 84/88**（与上游同口径：众数音名正确 **且** 偏差 < 50 音分） |
| A2 | 偏差统计 | 命中键偏差中位 **≤ 6.5 音分**、最大 ≤ 60 音分（上游 6.1 / 47.5） |
| A3 | 合成信号 | 22 个音 × 2 种信号（纯音 / 含 4 次泛音）音名全对；≤900 Hz 偏差 < 1 音分、900–1046.5 Hz < 8 音分 |
| A4 | 范围外信号 | 30–81 Hz、4500–8000 Hz（宽音域模式）返回无有效音高 |
| A5 | 噪声与静音 | 白噪声 30 次采样误报 ≤ 3；静音返回无有效音高 |
| A6 | 已知答案文件 | 440 Hz / 82.41 Hz / 吉他六弦 WAV 判定与上游一致（音名 + 偏差 ±1 音分内） |

### B 组｜跨语言一致性（本项目新增，AI 自动）

| # | 判据 | 通过标准 |
|---|---|---|
| B1 | 逐帧对拍 | 同一 WAV，C++ 与 JS 引擎逐帧 `freq` 相对差 ≤ 1e-6，音名完全一致 |
| B2 | 整段统计 | 命中键数、中位偏差、混合音名文件数与 JS 完全一致 |
| B3 | 参数同源 | C++ 常数与 `pitch-engine.js` 逐项比对，无差异（差异必须进 ADR） |

### C 组｜工程质量（AI 自动）

| # | 判据 | 通过标准 |
|---|---|---|
| C1 | 构建 | 0 error / 0 warning（`-Wall -Wextra` 或 MSVC `/W4`） |
| C2 | 单元测试 | `ctest` 全绿 |
| C3 | 分层检查 | `src/core/` 无 `#include <Q`；`qml/` 无算法符号（脚本检查） |
| C4 | 无预留代码 | 无"以后可能用到"的接口/参数（R8 YAGNI） |
| C5 | 注释 | 每个函数/分支/魔数有注释；无 >3 行说明性注释（超出的移文档，R11） |

### D 组｜人工与真机项（用户执行）

| # | 判据 | 通过标准 |
|---|---|---|
| D1 | 桌面实时闭环 | 发 440 Hz 标准音 → 显示 A4，偏差 ±5 音分内 |
| D2 | 吉他六弦 | 空弦显示 E2，不跳 E3 |
| D3 | 端到端延迟 | 体感可接受，且实测值记录进 `dev.md`（R8：性能必须量化） |
| D4 | 手机 APP（**首版重点**） | 安装、授予录音权限后实时显示正常；吉他六弦识别率可接受 |
| D5 | 文件分析 | 导入单音录音 → 曲线与音高走向一致，CSV 有值 |
| D6 | 音域测量 | 从低到高唱/奏一遍 → 最高/最低音与实际相符 |
| D7 | 四个底部导航入口切换 | 不丢当前会话状态，无报错 |

### E 组｜回归项（修 bug 后必补）

| # | 判据 |
|---|---|
| E1 | 低音 82.41 Hz 必须判为 E2 |
| E2 | 905–1046 Hz 不得报一半频率（τ 起点除以 2） |
| E3 | 白噪声不得输出音名 |
| E4 | 八度折回后必须重算音名/音分（不得出现假混合音名） |
| E5 | 判定必须双条件（音名 + 偏差 < 50 音分） |
| E6 | 素材路径缺失时测试必须 FAIL，不得静默跳过（pitfalls A7） |
